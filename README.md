# Captain PhD

Maritime læringsspill i nettleseren · Maritime learning games in the browser.
Site: https://captainphd.com (Hugo + GitHub Pages).

- `content/nb`, `content/en`: sider på norsk (bokmål) og engelsk / pages in Norwegian and English
- `static/<spill>/`: selve spillene, én HTML-fil hver / the games, one HTML file each
- Lokal forhåndsvisning / local preview: `hugo server`
